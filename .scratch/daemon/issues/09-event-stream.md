# 09: [zootree] 事件流:SSE、序号、断线续传、重新同步

**What to build:** Daemon 提供一条全局事件流。事件带单调递增序号,服务端保留最近 1000 条或 10 分钟。客户端可以用上次序号续传;缺口过大时收到重新同步事件并重新拉取快照。订阅顺序为先监听、再补发快照、最后标记就绪。Operation 的开始、进度、日志、结束,以及 Workspace 变化和移除都会作为事件发出。

**Blocked by:** 04 — [zootree] 外部命令逐行转发输出,服务层发出进度和日志事件; 07 — [zootree] Operation 核心,以及 done 和 cancel 端点

**Status:** done

- [ ] 订阅后先收到快照,再收到就绪标记;快照与订阅之间的变化不丢失
- [ ] 序号单调递增;带上次序号重连时只收到之后的事件
- [ ] 超过保留范围的续传请求收到重新同步事件
- [ ] 重连后的首次回放有明确标记
- [ ] Operation 运行期间能实时收到进度和日志事件
- [ ] 多个订阅者同时连接互不影响
