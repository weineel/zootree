# 10: [zootree] 外部变化检测

**What to build:** 用户在终端里手动编辑 Workspace 文件,或直接运行不经过 Daemon 的命令时,订阅者也能收到相应事件。有订阅者期间 Daemon 每 2 秒按修改时间和文件大小扫描相关目录;检测逻辑放在可替换的接口后面,以便以后换成文件系统监听而不改事件 API。

**Blocked by:** 09 — [zootree] 事件流:SSE、序号、断线续传、重新同步

**Status:** ready-for-agent

- [ ] 外部新增、修改、状态变化(目录移动)、删除 Workspace 都产生对应事件
- [ ] Repo 的变化也产生事件
- [ ] 没有订阅者时不扫描
- [ ] 同一秒内的连续修改不会漏掉(修改时间之外还比较大小)
- [ ] Daemon 自己的操作不会因扫描而重复发出事件
- [ ] 检测逻辑可以用测试替身替换
